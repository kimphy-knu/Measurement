내 데이터 열기

이 PC의 ARRES 로컬 서버가 폴더의 h5를 읽어 뷰어를 엽니다. 데이터는 PC 밖으로 나가지 않습니다.

로컬 서버 확인 중…

  1. ARRES 폴더의 run_live.bat를 실행해 둡니다 (검은 창은 열어 둔 채로). 새 컴퓨터라면 Python 3만 먼저 설치하세요 — 필요한 패키지는 처음 실행할 때 자동으로 깔립니다.
  2. 스핀 분해 EK / MM 스캔(*_ARRES_*.h5)이 있는 폴더 경로를 붙여 넣습니다.
  3. 처음 여는 폴더는 1~2분 걸리고, 같은 폴더는 다음부터 바로 열립니다.
